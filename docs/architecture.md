# 架构说明

## 概述

基于华为云 FunctionGraph + ModelArts 的无服务器ML推理服务，提供实时NLP问答能力。

## 架构图

```
用户请求
    │
    ▼
┌─────────────────────────────────────────────────────┐
│                    APIG 网关                       │
│              POST /nlp-qa                        │
└────────────────────────┬────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────┐
│              FunctionGraph 函数                    │
│         Python 3.9 + transformers              │
│    • 接收问答请求                              │
│    • 调用ModelArts推理端点                     │
│    • 日志写入OBS                               │
└────────────────────────┬────────────────────────────┘
                         │
            ┌────────────┴────────────┐
            ▼                         ▼
┌─────────────────────┐    ┌─────────────────────┐
│    OBS 日志桶       │    │   ModelArts        │
│  inference-logs    │    │   推理端点         │
└─────────────────────┘    └─────────────────────┘
```

## 资源清单

| 华为云资源 | 数量 |
|-----------|------|
| APIG API | 1 |
| FunctionGraph 函数 | 1 |
| OBS 桶 | 2 |
| IAM 委托 | 1 |

## 数据流

1. 用户通过APIG发送NLP问答请求
2. FunctionGraph函数接收请求
3. 函数调用ModelArts推理端点获取答案
4. 推理日志写入OBS桶
5. 响应返回给用户
